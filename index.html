What it is

Five states, tapped by hand

This page is the puck system, not a preview of one. Each disc holds one of two states, and the only way that state changes is by tapping it yourself. Nothing here updates on its own — no timer, no reminder, no notification deciding for you.

The pattern log above is how you see what you did without tracking it by hand: which puck you keep coming back to, which one goes quiet, and which one you reach for when it doesn't respond.

The object changes because the human changed it.
The display only reveals the state.

That's the whole filter, applied to this page: every state you see exists because you tapped it. If a puck earns a place in your day, it'll be because you keep flipping it — the log will show that. If it doesn't, the log shows that too.

A flip is a small, complete action — a shape for a moment, nothing more claimed than that.

Taps — a ritual object, not a product. Built primitive first.
